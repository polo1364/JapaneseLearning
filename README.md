# 🏮 商店街物語 LinguaMachi

經營一條日式商店街來學日文。學單字是「進貨」，複習是「盤點」，把一台路邊屋台養成一整條商店街。

介面沿用姊妹作「單字怪獸 LinguaMon」的風格：手機優先、底部五個分頁、立體按鈕。

## 怎麼開始

1. 用本機伺服器開啟（不能直接雙擊 `index.html`，瀏覽器會擋 API 呼叫與離線功能）：

   ```powershell
   python -m http.server 8791 --bind 127.0.0.1
   ```

   然後開 <http://localhost:8791>。也可以直接部署到 GitHub Pages。
2. 第一次開啟會請你幫屋台取名、選日語程度（N5–N1）。
3. 到「我的」分頁設定 Claude API Key。Key 只存在這台裝置的瀏覽器，直接送往 `api.anthropic.com`，費用算在你的 Anthropic 帳戶。預設模型是 Claude Opus 5.5，可在同一頁改成 Sonnet 5.5 或 Haiku 5.5。

## 五個分頁

| 分頁 | 內容 |
|---|---|
| 🏮 我的店 | 店面、四項數值、補貨／打掃／叫賣／裝潢、每日任務 |
| 🗾 商店街 | 16 條街，每條 5 關進貨＋1 位評論家；文法道場；五十音道場 |
| 📒 商品帳 | 學過的單字與熟練度、五十音表 |
| 💬 會話 | 39 個情境的 AI 角色扮演，可語音輸入 |
| ⚙️ 我的 | 統計、成就、程度、語速、API Key、匯出匯入 |

## 養成規則

- **進貨**：每關 Claude 出 5 個新單字，先看商品卡，再答 10 題（選意思、聽音、反查、讀音、排假名、打字）。答錯的題目會在最後再出一次。
- **評價**：店鋪的經驗值。Lv.5、Lv.10 各改裝一次，共三個階段。
- **新鮮度**：每小時 −2，低於 20% 評價減半。用食材補貨，或做盤點（複習）來補。
- **人氣**：每小時 −3，70% 以上評價 ×1.2。打掃、叫賣快答、會話可以提高。
- **常客**：進貨、打掃、會話會累積，每 20 點一顆心。
- **盤點**：單字依 1・3・7・14・30 天的間隔排入複習，答錯會回到第一格並進錯題本。
- **評論家**：完成一條街的 5 關後來訪，每題 15 秒、可錯 2 次。第一次通過會解鎖下一條街，並送一間空店面。
- **空店面**：答對 20 題整修完成後，開出一間新店（共 8 種）。

不需要網路也能玩的部分：盤點、五十音道場、叫賣快答、商品帳。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 整個遊戲（HTML、樣式、程式都在這一個檔案） |
| `tailwind.css` | 預先產生的排版工具類別 |
| `manifest.webmanifest`、`sw.js` | 安裝到手機與離線開啟 |
| `art/` | 店鋪與評論家的插圖（缺圖時自動改用表情符號） |
| `icons/` | App 圖示 |
| `index.html.bak.*` | 改版前的舊版 LinguaMax（Gemini 版）備份 |

存檔放在瀏覽器的 localStorage（鍵名 `shotengai_v1`）。第一次開啟時，舊版 LinguaMax 的經驗值會換成日圓，學過的單字不會再重複出現；舊資料不會被刪除。
