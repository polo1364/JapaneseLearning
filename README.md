# 🏮 商店街物語 LinguaMachi

經營一條日式商店街來學日文。學單字是「進貨」，複習是「盤點」，把一台路邊屋台養成一整條商店街。

介面沿用姊妹作「單字怪獸 LinguaMon」的風格：手機優先、底部五個分頁、立體按鈕。

## 怎麼開始

1. 用本機伺服器開啟（不能直接雙擊 `index.html`，瀏覽器會擋 API 呼叫與離線功能）：

   ```powershell
   python -m http.server 8791 --bind 127.0.0.1
   ```

   然後開 <http://localhost:8791>。也可以直接部署到 GitHub Pages。
2. 第一次開啟會請你幫屋台取名、選日語程度（N5–N1），接著自動開始 11 步的新手教學（可跳過，看完送 200 日圓；之後能在「我的」分頁重看）。
3. 到「我的」分頁設定 Claude API Key。Key 只存在這台裝置的瀏覽器，直接送往 `api.anthropic.com`，費用算在你的 Anthropic 帳戶。預設模型是 Claude Haiku 5.5，可在同一頁改成 Sonnet 5.5 或 Opus 5.5。

## 難度與風格

兩個設定分開選，都在「我的」分頁，可以自由搭配（例如 N3＋商務敬語）。

- **難度**：N5 入門、N4 基礎、N3 中級、N2 中高級、N1 高級，決定單字、文法與會話有多難。
- **風格**：決定同樣難度下偏向哪一種用語。

| 風格 | 偏向 |
|---|---|
| 一般 | 不特別偏向，均衡出題 |
| 旅遊生存 | 交通、購物、住宿、求助，馬上用得到的短句 |
| 商務敬語 | 職場用語與敬語：電話、會議、接待客戶 |
| 口語俗語 | 朋友之間的說法：普通形、縮約、常見俗語 |
| IT／工程 | 軟體開發與科技職場的用語 |
| 會話優先 | 可以直接複誦的短句、附和與固定說法 |

- **羅馬拼音**：難度是 N5 或 N4 時，單字卡片會自動附上羅馬拼音（題目卡、日文選項、答題結果、商品帳、接單、陳列配對、例句、會話回覆）。排假名的方塊、句子重組的方塊、選讀音的選項也都會顯示。可在「我的」分頁改成一律顯示或不顯示。只有打字題不顯示，因為羅馬拼音就是答案。

街區仍然決定主題（例如美食街就是餐廳用語），風格只影響在這個主題下挑哪些字、例句用什麼語氣。改了之後從下一關進貨、下一份文法講義、下一段會話開始生效，已經學過的單字不會變。

## 安裝成 App（PWA）

- **Android／電腦的 Chrome、Edge**：首頁會出現「安裝成 App」卡片，按「安裝」即可；也可以到「我的」分頁安裝。
- **iPhone／iPad**：用 Safari 開啟，點「分享」→「加入主畫面」。App 內的安裝按鈕會顯示這些步驟。
- 安裝後全螢幕開啟。第一次開啟時會把程式、插圖、圖示和字型樣式存到裝置上，之後沒有網路也能開，並可玩盤點、接單、陳列配對、五十音、叫賣。進貨、文法、會話需要網路。
- 長按 App 圖示有三個捷徑：盤點複習、接單、五十音道場（Android 與電腦支援）。
- 有新版本時，連線狀態下重新開啟就會拿到；若是開著的時候更新，會提示重新整理。

| 分頁 | 內容 |
|---|---|
| 🏮 我的店 | 店面、四項數值、補貨／打掃／叫賣／裝潢、每日任務 |
| 🗾 商店街 | 16 條街，每條 5 關進貨＋1 位評論家；文法道場；五十音道場 |
| 📒 商品帳 | 學過的單字與熟練度、五十音表 |

## 養成規則

- **進貨**：每關 Claude 出 5 個新單字，先看商品卡，再答 10 題（選意思、聽音、反查、讀音、排假名、打字）。答錯的題目會在最後再出一次。
- **評價**：店鋪的經驗值。Lv.5、Lv.10 各改裝一次，共三個階段。
- **新鮮度**：每小時 −2，低於 20% 評價減半。用食材補貨，或做盤點（複習）來補。
- **人氣**：每小時 −3，70% 以上評價 ×1.2。打掃、叫賣快答、會話可以提高。
- **常客**：進貨、打掃、會話會累積，每 20 點一顆心。
- **盤點**：單字依 1・3・7・14・30 天的間隔排入複習，答錯會回到第一格並進錯題本。
- **評論家**：完成一條街的 5 關後來訪，每題 15 秒、可錯 2 次。第一次通過會解鎖下一條街，並送一間空店面。
- **空店面**：答對 20 題整修完成後，開出一間新店（共 8 種）。

- **接單**：5 位客人輪流用日文點 1–3 件商品，每位 20 秒內從貨架挑出來。賺日圓、人氣和常客；一次都沒挑錯有小費。商品帳要有 6 個單字才能玩。
- **陳列配對**：翻牌把 6 組商品和意思配成對。步數越少日圓越多，並補新鮮度 10。單字不足 6 個時改用假名和讀音。
- **每日開店獎勵**：每天第一次開啟送日圓（50 起，連續天數每天多 20，最多 7 天）和 1 份基本食材。
- **句子重組、例句聽力**：新進貨的單字會附上分段的例句，多出「把句子排出來」和「聽例句選意思」兩種題型。
- **星級評鑑**：通過普通評鑑後可以再挑戰。沒有選項，全部要自己排假名、打字或排句子，每題多 10 秒。通過後該街掛上星級標章。
- **營業額**：不在線上時店鋪照常營業，回來按「收款」領取，最多累積 8 小時。店的階段越高、新鮮度和人氣越高，賺得越多。
- **商店街等級**：店鋪等級、通過的評鑑和單字量累積成發展度，共五級（無名小巷 → 傳說商店街）。每升一級送日圓，營業額 +10%。
- **設備升級**：每間店可各自升級冷藏庫（新鮮度下降 −15%／級）、招牌（人氣下降 −15%／級）、座位（營業額 +20%／級），各 3 級，費用 400／1000／2500 日圓。第 2、3 級要等店鋪改裝到對應階段。
- **店員**：通過一條街的評鑑後，那位評論家會成為常客，可以請來當店員，一間店一位。技能分四種：營業額 +15%、評價 +10%、新鮮度下降 −30%、人氣下降 −30%。
- **上架商品**：把學過的單字擺上店鋪貨架（2／4／6 格，隨改裝增加）。每件商品依熟練度加營業額，每顆星 +4%；到期沒盤點的商品會過期，不計加成。
- **常客送禮**：常客每多一顆心，這間店的評價 +3%（最多 +15%），常客還會送日圓和食材。
- **經營路線**：店鋪改裝到最終階段後二選一。老舖路線：營業額 +20%、常客好感獲得 ×2。潮流路線：人氣下降 −40%、當主力店時接單和叫賣的日圓 +50%。第一次免費，之後轉換要 2000 日圓。
- **店址**：通過評鑑的街可以進駐，一條街最多 2 間店。進駐 +10% 營業額，街區適合這種店再 +25%，該街有星級評鑑再 +15%。
- **今日話題**：每天輪替一個全店加成（大特賣日、美食節、電視採訪、下雨天、祭典、早市），顯示在首頁。
- **店主技能**：累計答對題數會讓店主升級，每級 1 技能點，在「我的」分頁學技能。共六種：鑑定眼（選擇題提示）、護身符（評鑑多幾顆心）、連擊術、記憶術、好嗓門、殺價術。可花 1000 日圓重學。
- **暖簾分け**：店鋪到 Lv.20 可以回到 Lv.1，換永久的營業額 +25%、評價 +10%，並拿日圓獎勵，最多 5 次。設備、店員、店址、常客都保留。
- **本週目標**：每週一重置的四項目標（進貨、答對、接單、盤點），四項都領完還有大獎。
- **店鋪特性**：擁有某種店就有對應加成，店的種類越多加成越多。

| 店 | 特性 |
|---|---|
| 屋台 | 叫賣時間 +5 秒 |
| 便利商店 | 進貨的日圓 +20% |
| 拉麵店 | 所有評價 +10% |
| 喫茶店 | 人氣下降速度減半 |
| 壽司店 | 盤點的日圓 ×2 |
| 藥妝店 | 新鮮度下降速度減半 |
| 車站賣店 | 評論家每題多 5 秒 |
| 溫泉旅館 | 常客好感每次多 +1 |

不需要網路也能玩的部分：盤點、接單、陳列配對、五十音道場、叫賣快答、商品帳。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 整個遊戲（HTML、樣式、程式都在這一個檔案） |
| `tailwind.css` | 預先產生的排版工具類別 |
| `manifest.webmanifest`、`sw.js` | 安裝到手機與離線開啟 |
| `art/` | 店鋪與評論家的插圖（缺圖時自動改用表情符號） |
| `icons/` | App 圖示 |
| `index.html.bak.*` | 改版前的舊版 LinguaMax（Gemini 版）備份 |

存檔放在瀏覽器的 localStorage（鍵名 `shotengai_v1`）。第一次開啟時，舊版 LinguaMax 的經驗值會換成日圓，學過的單字不會再重複出現；舊資料不會被刪除。
